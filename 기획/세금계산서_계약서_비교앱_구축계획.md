# 로컬 WebUI 기반 세금계산서·계약서 비교 프로그램

## 확정 요구사항
- EXE 실행 시 로컬 서버와 기본 브라우저 WebUI를 연다. Python·Node 별도 설치 없이 사용한다.
- 인터넷 연결 시 새봄 그룹웨어의 전체 메일·계약 목록을 최신 상태로 갱신한다.
- 메일 다중 선택 → 계약 추천·수정 → 선택 PDF 다운로드 → 비교 → 결과·이력 조회 흐름이다.
- PDF만 처리한다. PNG만 첨부된 메일은 제외 사유를 표시한다.
- 다운로드 후 비교·원문 보기·이력·CSV 내보내기는 인터넷 없이 동작한다.
- AI·AI API·OCR을 사용하지 않는다. 이미지 PDF는 확인 필요로 처리한다.

## 기술 구성
React·TypeScript·Vite WebUI, Python 3.12·FastAPI·Uvicorn 로컬 서버, Playwright 전용 브라우저, pdfplumber 텍스트·표 추출, PDF.js 로컬 원문 뷰어, SQLite 저장, PyInstaller 폴더형 배포.
기본 데이터는 %LOCALAPPDATA%/SaebomCompare에 저장한다. 서버는 127.0.0.1만 사용하며 실행별 세션 토큰·출처 검증을 적용한다. 중복 실행 시 기존 화면을 열고, 종료 버튼으로 앱 전용 서버와 브라우저만 정리한다.

## 추가 확정: 원본 PDF 저장 설정
설정 화면에서 로컬 저장 폴더를 선택한다. 지정 폴더 아래 세금계산서/ 및 계약서/ 하위 폴더에 원본 PDF를 종류별로 저장한다. 파일명 앞에 해시 일부를 붙여 동명 파일 충돌을 막는다. 설정 변경은 이후 다운로드부터 적용하고 기존 문서는 기록된 경로로 계속 조회한다. DB·설정·로그는 기본 앱 데이터 폴더에 유지한다.

## 화면
메일 목록(업체·날짜 검색, PDF·저장 상태), 계약 연결(추천·직접 변경), 작업 진행률, 비교 결과(항목·차이·원문 근거·두 PDF 보기), 이력·설정·종료.
메일 ID·계약 관리번호로 동기화하고 파일 해시로 재사용한다. 갱신·다운로드 실패는 기존 데이터를 보존한다.

## 비교 규칙
사업자등록번호 우선, 없으면 법인 표기·공백을 정리한 업체명으로 추천한다. 지출 계약 우선이며 사용자가 변경할 수 있다.
공급가액·세액·합계·부가세 포함/별도·청구기간·계약기간·월정액/총액/분할 지급을 대조한다. 발행일을 청구기간으로 대체하지 않는다.
추출값에 원문·페이지·추출방법을 보관하고 수동 수정 전후를 이력으로 저장한다.
결과: 일치 / 불일치 / 확인 필요 / 처리 실패. 정보 누락이나 모호한 표현을 일치로 처리하지 않는다.
초기 지원은 현재 새봄 그룹웨어 PDF 양식이며 임의의 계약 조항 의미 해석은 포함하지 않는다.

## 검증 및 배포
목록 중복 방지, 선택 PDF만 저장, PDF 없음·암호화·손상·이미지 PDF 처리, 부가세·금액 차이·기간 초과·분할 지급, 모호한 연결, 네트워크 실패 보존을 검증한다.
EXE 실행·중복 실행·종료와 네트워크 차단 후 재실행·비교·PDF 보기·CSV 저장을 확인한다.
EXE·라이브러리·WebUI·자동화 브라우저를 포함한 ZIP을 배포하며 데이터는 배포 폴더 밖에 유지한다.
