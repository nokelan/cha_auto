## 실행 순서
1. 0단계 준비(메인) → 2. 1단계 병렬(A·B·F) → 메인 통합 검사 → 3. 2단계 → 검사 → 4. 3단계 → 검사 → 5. 사용자 확인 후 실사이트 검사·EXE 재빌드(선택) → 6. 문서 작성(병렬 4개: [02·05·06], [03·04·07], [01·08·09·10], [11·12·13·14·00]; 파일 소유 분리) → 7. 문서 검증 → 8. `07_auto/CLAUDE.md`에 개발문서 포인터 추가·위키 `project-07-auto` 기록·훅 `done`
- 각 단계마다 서브에이전트가 만든 결과를 메인이 코드로 재확인한다(에이전트 보고를 그대로 믿지 않음 — 이번 세션에서 `result_summaries` 잠금 주장이 틀렸던 선례).
- 서브에이전트는 소유 구간 밖 파일을 고치지 않고, 새 동작에는 테스트를, 변경 함수에는 한글 기능명세를 갱신한다.
